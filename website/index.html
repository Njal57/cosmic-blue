COSMIC, ready to use

System76's Rust desktop from the official Fedora packages, with a blue theme, frosted glass panels, Papirus icons and a matching boot screen out of the box.

Atomic and reversible

The system is a signed container image. Updates download in the background and apply on the next boot. If something breaks, boot the previous version.

Bluefin and Aurora's foundation

The Universal Blue base and tools they share: ujust commands, Homebrew for command line tools, Flathub apps in the COSMIC Store, and ujust devmode for developer tools.

Install

From the live ISO

  1. Download the live ISO above.
  2. Write it to a USB stick with Fedora Media Writer.
  3. Boot from the stick: you get a full COSMIC desktop to try.
  4. Start the installer from the desktop icon.

From another bootc system

Already on Bluefin, Aurora, Bazzite or a Fedora Atomic desktop (Silverblue, Kinoite...)? Switch in place:

sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:latest
sudo systemctl reboot

Updates and rollback

ujust update          # update now instead of waiting
sudo bootc rollback   # go back to the previous version on next boot

Signed images

Every image is signed with cosign, and installed systems refuse unsigned updates. Check by hand with cosign.pub:

cosign verify --key cosign.pub ghcr.io/cosmic-blue-os/cosmic-blue:latest
