Documentation

Ce qu'il faut savoir pour utiliser cosmic-blue au quotidien. cosmic-blue est une image Universal Blue, comme Bluefin et Aurora : le système est en lecture seule et mis à jour d'un bloc, vos applications et vos fichiers vivent à part.

Mises à jour et retour en arrière

Le système, les applications Flatpak et les paquets Homebrew se mettent à jour seuls en arrière-plan. Une mise à jour du système s'applique au prochain démarrage. Pour mettre à jour tout de suite, ou couper les mises à jour automatiques :

ujust update           # tout mettre à jour maintenant
ujust toggle-updates   # activer ou couper les mises à jour automatiques

Si une mise à jour casse quelque chose, revenez à la version précédente. Elle reste installée jusqu'à la mise à jour suivante, donc cela marche sans réseau :

sudo bootc rollback    # utiliser la version précédente au prochain démarrage
sudo systemctl reboot
sudo bootc status      # voir la version actuelle et la précédente

Installer des logiciels

Applications : COSMIC Store

Les applications graphiques sont des Flatpak, installées depuis le COSMIC Store, qui affiche Flathub et les applications COSMIC. Elles se mettent à jour avec le système et n'y touchent pas.

Outils en ligne de commande : Homebrew

Les outils en ligne de commande s'installent dans votre dossier personnel avec Homebrew :

brew search ripgrep
brew install ripgrep

Paquets d'autres distributions : Distrobox

Besoin d'un paquet qui n'existe que pour une autre distribution ? Distrobox le fait tourner dans un conteneur qui partage votre dossier personnel :

distrobox create --name arch --image archlinux:latest
distrobox enter arch

Outils de développement

Le mode développeur ajoute Docker, Podman Desktop, VS Code et d'autres IDE, Lima et plus encore. Choisissez ce que vous voulez dans un menu :

ujust devmode

Commandes ujust

ujust lance les raccourcis fournis avec le système. Lancez ujust seul pour tous les lister, ou ujust --choose pour en choisir un dans un menu. Les plus utiles :

ujust update
Mettre à jour le système, les applications Flatpak et les paquets Homebrew tout de suite.
ujust toggle-updates
Activer ou couper les mises à jour automatiques.
ujust devmode
Installer des outils de développement.
ujust toggle-dark-mode
Passer du thème sombre au thème clair, et inversement.
ujust reset-cosmic-theme
Restaurer le style cosmic-blue : couleurs, icônes, fond d'écran.
ujust reset-cosmic-config
Remettre tous les réglages COSMIC par défaut de cosmic-blue (une sauvegarde est gardée).
ujust install-microsoft-fonts
Télécharger les polices de base de Microsoft (Arial, Times New Roman, Verdana…) pour votre compte, après avoir accepté leur licence.
ujust toggle-tpm2
Déverrouiller un disque chiffré avec la puce TPM2 au lieu d'un mot de passe.
ujust enroll-secure-boot-key
Image NVIDIA avec Secure Boot : enregistrer la clé qui permet de charger le pilote.

Apparence

cosmic-blue arrive avec un thème COSMIC bleu, des panneaux en verre dépoli, des fonds d'écran, icônes et curseurs cosmic-blue. Tout se change dans les Paramètres. Pour retrouver le style d'origine :

ujust reset-cosmic-theme

Terminal

Chaque nouveau terminal affiche un message d'accueil avec une astuce. ff affiche les informations du système. Pour désactiver le message d'accueil, ou le réactiver :

uwelcome toggle

Obtenir de l'aide

Un bug ou quelque chose de pas clair ? Signalez un problème sur GitHub (en anglais de préférence). Dites ce que vous avez fait, ce qui s'est passé, et ajoutez le résultat de :

sudo bootc status

cosmic-blue est construit sur Universal Blue, Bluefin, Fedora et COSMIC. Sans lien officiel avec ces projets.
