COSMIC, prêt à l’emploi

Le bureau en Rust de System76, issu des paquets officiels de Fedora, avec un thème bleu, des panneaux en verre dépoli, les icônes Tela circle et un écran de démarrage assorti, dès l’installation.

Atomique et réversible

Le système est une image de conteneur signée. Les mises à jour se téléchargent en arrière-plan et s’appliquent au démarrage suivant. En cas de problème, démarrez sur la version précédente.

Les fondations de Bluefin et Aurora

La base Universal Blue et les outils qu’ils partagent : les commandes ujust, Homebrew pour les outils en ligne de commande, les applications Flathub dans le COSMIC Store, et ujust devmode pour les outils de développement.

Installation

Depuis l’ISO live

  1. Téléchargez l’ISO live ci-dessus.
  2. Écrivez-la sur une clé USB avec Fedora Media Writer.
  3. Démarrez sur la clé : vous obtenez un bureau COSMIC complet à essayer.
  4. Lancez l’installateur depuis l’icône du bureau.
  5. Si Secure Boot est activé, un écran bleu s’affiche au premier redémarrage : choisissez Enroll MOK, puis Continue, et tapez le mot de passe universalblue (clavier QWERTY). Cela permet au pilote NVIDIA de se charger.

Depuis un autre système bootc

Déjà sur Bluefin, Aurora, Bazzite ou un bureau Fedora Atomic (Silverblue, Kinoite…) ? Basculez sur place :

ujust enroll-secure-boot-key   # seulement si Secure Boot est activé
sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:latest
sudo systemctl reboot

Mises à jour et retour en arrière

ujust update          # mettre à jour maintenant sans attendre
sudo bootc rollback   # revenir à la version précédente au prochain démarrage

Images signées

Chaque image est signée avec cosign, et les systèmes installés refusent les mises à jour non signées. Pour vérifier à la main avec cosign.pub :

cosign verify --key cosign.pub ghcr.io/cosmic-blue-os/cosmic-blue:latest
