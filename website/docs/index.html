What you need to know to use cosmic-blue day to day. cosmic-blue is a Universal Blue image, like Bluefin and Aurora: the system is read-only and updated as a whole, and your apps and files live apart from it.

Updates and rollback

The system, Flatpak apps and Homebrew packages update by themselves in the background. A system update applies on the next boot. To update now, or to turn the automatic updates off:

ujust update           # update everything now
ujust toggle-updates   # turn automatic updates on or off

If an update breaks something, go back to the previous version. It stays installed until the next update, so this works offline:

sudo bootc rollback    # use the previous version on next boot
sudo systemctl reboot
sudo bootc status      # see the current and previous versions

Installing software

Apps: COSMIC Store

Graphical apps come as Flatpaks from the COSMIC Store, which shows Flathub and the COSMIC apps. They update with the system and do not touch it.

Command line tools: Homebrew

Command line tools install in your home folder with Homebrew:

brew search ripgrep
brew install ripgrep

Packages from other distributions: Distrobox

Need a package that only exists for another distribution? Distrobox runs it in a container that shares your home folder:

distrobox create --name arch --image archlinux:latest
distrobox enter arch

Developer tools

Developer mode adds Docker, Podman Desktop, VS Code and other IDEs, Lima and more. Pick what you want from a menu:

ujust devmode

ujust commands

ujust runs the shortcuts that come with the system. Run ujust alone to list them all, or ujust --choose to pick one from a menu. The most useful ones:

ujust update
Update the system, Flatpak apps and Homebrew packages now.
ujust toggle-updates
Turn automatic updates on or off.
ujust devmode
Install developer tools.
ujust toggle-dark-mode
Switch between the dark and light themes.
ujust reset-cosmic-theme
Restore the cosmic-blue look: colors, icons, wallpaper.
ujust reset-cosmic-config
Reset all COSMIC settings to the cosmic-blue defaults (a backup is kept).
ujust install-microsoft-fonts
Download Microsoft's core fonts (Arial, Times New Roman, Verdana...) for your account, after accepting their license.
ujust toggle-tpm2
Unlock an encrypted disk with the TPM2 chip instead of a password.
ujust enroll-secure-boot-key
NVIDIA image with Secure Boot: enroll the key that lets the driver load.

The look

cosmic-blue comes with a blue COSMIC theme, frosted glass panels, cosmic-blue wallpapers, icons and cursors. Change anything in Settings. If you want the original look back:

ujust reset-cosmic-theme

Terminal

Each new terminal shows a welcome message with a tip. ff shows the system information. To turn the welcome message off, or back on:

uwelcome toggle

Getting help

Found a bug or something unclear? Report a problem on GitHub. Please say what you did, what happened, and add the output of:

sudo bootc status
